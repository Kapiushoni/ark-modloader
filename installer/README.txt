ArkModLoader — загрузчик модов для ARK Mobile 2.0.29 (эмулятор MuMu Player 12)

УСТАНОВКА
  1. В MuMu включите root: Настройки MuMu -> Другое -> Root-права (и перезапустите эмулятор).
  2. Нужен Python 3 с python.org (галочка "Add to PATH") — им установщик готовит файл игры
     у вас на компьютере. При первом запуске нужен интернет.
  3. Дважды щёлкните install.bat.
     Если игры ещё нет в эмуляторе, установщик предложит поставить её из .xapk в папке
     "Загрузки" (или: install.bat -Xapk "путь\к\файлу.xapk").
  4. В главном меню под EXIT появится пункт MODS, в одиночной игре — кнопка MODS сверху по центру.

УДАЛЕНИЕ
  Дважды щёлкните uninstall.bat — оригинальные файлы игры вернутся
  (резервная копия оригинала хранится в %LOCALAPPDATA%\ArkModLoader\backup).

МОДЫ
  Папка в эмуляторе: /sdcard/Android/data/com.studiowildcard.wardrumstudios.ark/files/ArkMods/
    *.so   — моды на C++        *.lua — моды на Lua (обычный текст, можно править)
    <мод>.ini — настройки мода   mods.ini — какие моды включены   loader.log — лог
  Моды и настройки подхватываются на ходу, перезапуск игры не нужен.
  Включать/выключать моды и их функции можно через MODS — в главном меню или в игре.

ОБНОВЛЕНИЕ
  Запустите install.bat из новой версии — моды и настройки сохранятся.

Только для одиночной игры и неофициальных серверов.
