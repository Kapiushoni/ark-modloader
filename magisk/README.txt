ArkModLoader для телефона — Magisk-модуль (ARK Mobile 2.0.29, Android 7+, arm64)

ЧТО НУЖНО
  - root через Magisk с включённым Zygisk (Magisk -> Настройки -> Zygisk),
    или KernelSU / APatch + модуль ZygiskNext;
  - ARK Mobile 2.0.29 (можно поставить и после модуля).

УСТАНОВКА
  1. Скопируйте ArkModLoader-<версия>-magisk.zip на телефон.
  2. Magisk -> Модули -> Установить из хранилища -> выберите zip.
  3. Перезагрузите телефон, запустите игру и зайдите в одиночную игру —
     справа вверху появится кнопка MODS.
  Игра в DenyList Magisk быть не должна (в такие приложения модули не загружаются).

МОДЫ
  Папка: Android/data/com.studiowildcard.wardrumstudios.ark/files/ArkMods/
    *.so  — моды на C++          *.lua — моды на Lua (обычный текст)
    <мод>.ini — настройки мода   mods.ini — какие моды включены   loader.log — лог
  Моды из комплекта копируются туда при первом запуске игры и после обновления модуля.
  Свои моды просто кладите в эту папку — подхватятся на ходу.
  Если Android не пускает в папку Android/data, используйте файловый менеджер с root
  (например, MT Manager) или путь /data/media/0/Android/data/...

ОБНОВЛЕНИЕ
  Установите zip новой версии поверх в Magisk и перезагрузитесь. Моды и настройки сохранятся.

УДАЛЕНИЕ
  Magisk -> Модули -> ArkModLoader -> Удалить, перезагрузка. Файлы игры модуль не меняет,
  поэтому восстанавливать ничего не нужно. Папка ArkMods остаётся.

ЕСЛИ НЕ РАБОТАЕТ
  Лог: ArkMods/loader.log. Если его нет — загрузчик не запустился:
  adb logcat -s ArkModLoader-zygisk ArkModLoader

Только для одиночной игры и неофициальных серверов.
